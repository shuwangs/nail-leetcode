# 42. Trapping Rain Water

---

```python
class Solution(object):
    def trap(self, height):
        """
        :type height: List[int]
        :rtype: int
        """
        left = 0
        right = len(height) - 1
        left_flag = height[0]
        right_flag = height[len(height) - 1]
        trap = 0
        while left < right:
            if left_flag <= right_flag:
                if height[left] >= left_flag:
                    left_flag = height[left]
                else:
                    trap += left_flag - height[left]
                left += 1
            else:
                right -= 1
                if height[right] > right_flag:
                    right_flag = height[right]
                else:
                    trap += right_flag - height[right]

        return trap 
```
