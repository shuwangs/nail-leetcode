# Array and Hashing:

## 1. Two Sum

```python
class Solution(object):
    def twoSum(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: List[int]
        """
        records = dict() # Keep the seen value and their indices
        for index, value in enumerate(nums):
            complement = target - value
            if complement in records:
                return [records[complement], index]
            else:
                records[value] = index # use value as key
```
