# Array and Hashing:

## 1. Two Sum

```python
class Solution(object):
    def twoSum(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: List[int]
        """
        records = dict() # Keep the seen value and their indices
        for index, value in enumerate(nums):
            complement = target - value
            if complement in records:
                return [records[complement], index]
            else:
                records[value] = index # use value as key
```

### 217. Contains Duplicate

```python
class Solution(object):
    def containsDuplicate(self, nums):
        """
        :type nums: List[int]
        :rtype: bool
        """
        records = set()
        for num in nums:
            if num in records:
                return True
            else:
                records.add(num)
        return False
```

题目	算法方法	数据结构	时间复杂度	本质问题类型
Two Sum	哈希表 + 一次遍历查找补数	dict	O(n)	查找 / 配对问题
Contains Duplicate	哈希集合判断是否重复	set	O(n)	判重 / 去重问题
