## 1. Two Sum

```python
class Solution(object):
    def twoSum(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: List[int]
        """
        records = dict() # Keep the seen value and their indices
        for index, value in enumerate(nums):
            complement = target - value
            if complement in records:
                return [records[complement], index]
            else:
                records[value] = index # use value as key
```

### 217. Contains Duplicate

```python
class Solution(object):
    def containsDuplicate(self, nums):
        """
        :type nums: List[int]
        :rtype: bool
        """
        records = set()
        for num in nums:
            if num in records:
                return True
            else:
                records.add(num)
        return False
```

### 242. Valid Anagram

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        records = dict()
        for single_s in s:
            if single_s in records:
                records[single_s] +=1
            else:
                records[single_s] = 1
        
        for single_t in t:
            if single_t not in records:
                return False
            else:
                records[single_t] -= 1
        
        for record in records:
            if records[record] != 0:
                return False
        return True
```
- **Time Complexity**: O(n + m)
    n = len(s), m = len(t)
    First loop counts characters in s → O(n)
    Second loop subtracts counts using t → O(m)
    Final loop checks for non-zero counts → at most O(n) (number of unique characters in s)
    ✅ Overall: O(n + m)

- **Space Complexity**: O(k)
    Where k is the number of unique characters in s (at most O(n) in the worst case)

A dict is used to store character frequencies
