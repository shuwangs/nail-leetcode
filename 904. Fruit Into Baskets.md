# 904. Fruit Into Baskets
```python
class Solution:
    def totalFruit(self, fruits: List[int]) -> int:
        #   create empty map count
        count = defaultdict(int)
        start = 0
        max_len = 0

        # loop through the trees if 
            # fruits species counts is greater than 2, and shorten the window, 
            # and remove the first type of the count table
            # check the size from left to end.
        for end in range(len(fruits)):
            fruit = fruits[end]
            count[fruit] += 1

            while len(count) > 2 :
                left_fruit = fruits[start]
                count[left_fruit] -= 1
                if count[left_fruit] == 0:
                    del count[fruits[start]]
                start += 1
            max_len = max(max_len,  end - start + 1)
        return max_len
```

---

解题思路

滑动窗口（two pointers）

用 start 和 end 维护一个连续区间 [start, end]。

end 每次向右扩展，表示多摘一个水果。

如果区间内的水果种类 ≤ 2，就继续扩展；

如果超过 2 种，就移动 start 缩小窗口，直到种类 ≤ 2。

统计水果种类

用 count（字典）记录当前窗口内每种水果的数量。

当某种水果数量减到 0，就从字典删除（种类数减少）。

更新最大长度

每次调整好窗口后，end - start + 1 就是当前能采的水果数。

不断取最大值。
