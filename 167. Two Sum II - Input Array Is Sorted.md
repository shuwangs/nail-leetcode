# 167. Two Sum II - Input Array Is Sorted

---

```python
class Solution:
    def twoSum(self, numbers: List[int], target: int) -> List[int]:
        left = 0
        right = len(numbers) - 1

        while left < right:
            if numbers[left] + numbers[right] < target:
                left += 1
            elif numbers[left] + numbers[right] > target:
                right -= 1
            else:
                return [left + 1, right + 1]
```

---

Double pointer is amazing in solving this! 

时间复杂度：O(n)
左右指针各最多移动 n 次，指针只会向中间单调推进，不会回退，因此总比较次数是线性的。

空间复杂度：O(1)
只使用了常数个变量（left, right），不随输入规模增长而增加额外空间。
