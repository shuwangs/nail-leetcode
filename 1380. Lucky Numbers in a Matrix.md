# 1380. Lucky Numbers in a Matrix

---

```python
class Solution:
    def luckyNumbers(self, matrix: List[List[int]]) -> List[int]:
        row_min_list= [min(row) for row in matrix]

        print(row_min_list)
        
        middle = list(zip(*matrix)) # * matrix unpack the matrix, and make them as the input of the zip => return is a zip object
        col_max_list = [max(col) for col in middle]

        print(col_max_list)

        res = []

        for num in row_min_list:
            if num in col_max_list:
                res.append(num)
        return res
```
