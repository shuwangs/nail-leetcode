# 76. Minimum Window Substring
---

```python
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        # make a key to store the target
        target = Counter(t)
        target_types = len(target)

        # initialize a window
        window = defaultdict(int)   # let not exist to be 0

        # use formed to signal whether should move or not, compare formed with target_types, only when char need counts meet increase it
        formed = 0
        left = 0
        best_len = float('inf')
        best_left = 0  # 记录最优左端

        for end in range(len(s)):
            cur = s[end]
            window[cur] += 1 
            # print(window)

            if cur in target and window[cur] == target[cur]:
                formed += 1

            while formed == target_types:
                cur_len = end - left + 1

                if cur_len < best_len:
                    best_len = cur_len
                    best_left = left

                left_char = s[left]
                window[left_char] -= 1

                if left_char in window and window[left_char] < target[left_char]:
                    formed  -= 1
                left += 1

        return "" if best_len == float('inf') else s[best_left : best_left + best_len]            

    ```
- Must be aware of the following key points:
  - 用了 formed == target_types 判覆盖
  - formed += 1 只在 == 时触发且仅对目标字符
  - 收缩时自减→跌破→formed -= 1 的顺序正确
  - 用了 defaultdict(int) 或 .get，不会 KeyError
- 维护了 best_len/best_left，返回用最优切片
