# 238. Product of Array Except Self

这里花了一点时间来消化。
left[] 包含了从左边开始iterate，的不包括当前 i 的 乘积 - O(n)
right[] 从右边开始iterate， 但一定要注意的是我append后顺序是跟原array相反- O(n) +  O(n)
所以需要**Reverse**一下
最后在iterate一遍两个array each position相乘 - O(n)
- 应该可以继续优化

```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        left = []
        right = []

        n = len(nums)
        # Start the left side iteration
        res_left = 1
        for i in range(n):
            if i == 0:
                res_left = 1
            else:
                res_left *= nums[i - 1]
            left.append(res_left)

        # Start the right side interation
        res_right = 1
        # from the right side to left iteration
        for i in range(n - 1, -1, -1):
            if i == n - 1:
                res_right = 1
            else:
                res_right *= nums[i + 1]
            right.append(res_right)

        right = right[::-1]

        final = []
        for i in range(n) :
            cur = left[i] * right[i]
            final.append(cur)

        return final
```
