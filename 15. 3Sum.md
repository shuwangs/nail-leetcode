# 15. 3Sum

---
```python
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        res = []
        nums.sort()

        for i in range(len(nums) - 1):
            if i > 0 and nums[i] == nums[i-1]:
                    continue
            left = i + 1
            right = len(nums) -1
            while left < right:
                cur = nums[i] + nums[left] + nums[right]

                if cur ==0:
                    res.append([nums[i], nums[left], nums[right]])

                    while left < right and nums[left] == nums[left + 1]:
                        left += 1
                    while left < right and nums[right] == nums[right -1]:
                        right -= 1
                    left += 1
                    right -= 1
                elif cur < 0:
                    left += 1
                else:
                    right -= 1
        return res
```
其实用双指针法解这道题还是挺麻烦的，消耗O(n**2), 我觉得我会忘记很多edge cases.
1.当基点与前一个基点相同时，跳过本次循环
2.如上面说到的基于当前基点继续寻找三元数组时，left 和 right都要各自往左右移动，那么在左移或右移后有可能碰到相同项，那么就需要继续移动 - > remove duplicates
