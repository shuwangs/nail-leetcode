# 121. Best Time to Buy and Sell Stock
---
```python
class Solution(object):
    def maxProfit(self, prices):
        """
        :type prices: List[int]
        :rtype: int
        """
        if not prices or len(prices) < 2:
            return 0
        
        left_min = 0         
        profit = 0
        cur = 1
        while cur < len(prices):
            if prices[cur] < prices[left_min] :
                left_min = cur
                cur_profit = prices[cur] - prices[left_min]
                profit = max(cur_profit, profit)
            else: 
                profit = max(profit, prices[cur] - prices[left_min])
            cur += 1

        if profit <= 0:
            return 0
        else:
            return profit
```

一道Easy题被我做的又臭又长，双指针法 不总是最优解。
另一个方法反而看起来更简单-- 贪心算法，每一步都作当前最优解
```python
class Solution(object):
    def maxProfit(self, prices):
        """
        :type prices: List[int]
        :rtype: int
        """
        if not prices or len(prices) < 2:
            return 0

        min_price = prices[0]
        profit = 0

        for p in prices[1:]:
            # if sell today, what is the profit
            profit = max(profit, p - min_price)
            # buy at the lower price 
            min_price = min(min_price, p)

        return profit
```

“记录历史最低价，每天都尝试卖出，更新最大利润”
