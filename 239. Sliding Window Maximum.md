# 239. Sliding Window Maximum

---

```python
class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        if k <= 0 or n == 0:
            return []
        if k == 1:
            return nums[:]

        ans = []
        start = 0
        for end in range(n):
            if end - start + 1 == k:
                ans.append(max(nums[start:end+1]))
                start += 1
        return ans
```
---

朴素滑窗 + 每次重算最大值
总时间 O((n−k+1)·k) ≈ O(nk)
