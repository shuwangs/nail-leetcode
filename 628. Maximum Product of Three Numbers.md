# 628 Maximum Product of Three Numbers

## Method 1
```python
class Solution:
    def maximumProduct(self, nums: List[int]) -> int:
        sorted_nums = sorted(nums)
        return max(sorted_nums[0]*sorted_nums[1]* sorted_nums[len(nums) -1], 
        sorted_nums[len(nums)-1] *sorted_nums[len(nums)-2]*sorted_nums[len(nums)-3])
```
Time Cost: O(n log n) + O(1) + O(1) = O(n log n)
✅ Sorting an array of length n: → O(n log n)
✅ Accessing sorted list elements & multiplying: → O(1) (constant time)
✅ Taking the max of two numbers: → O(1)

Take-home point is: 
🚀 最重要要比较两种情况：
1️⃣ largest1 × largest2 × largest3
2️⃣ smallest1 × smallest2 × largest1

## Method 2

```python
class Solution:
    def maximumProduct(self, nums: List[int]) -> int:
        max1 = max2 = max3 = float('-inf')
        min1 = min2 = INF = float('inf')

        for num in nums:
            if num > max1:
                max3 = max2
                max2 = max1
                max1 = num
            elif num > max2:
                max3 = max2
                max2 = num
            elif num > max3:
                max3 = num
            
            if num < min1:
                min2 = min1
                min1 = num
            elif num < min2:
                min2 = num
        
        return max(min1*min2* max1, max1* max2* max3)
```
Take-home point is: 
🚀 最重要要是loop一次，把最大和最小都给搞定了。
