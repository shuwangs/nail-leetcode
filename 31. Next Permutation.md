# 31. Next Permutation

---

```python
class Solution(object):
    def nextPermutation(self, nums):
        """
        :type nums: List[int]
        :rtype: None Do not return anything, modify nums in-place instead.
        """
        nums_len = len(nums)
        i = len(nums) - 2

        # Get the point when nums starts to decrease from left to right
        while i >= 0 and nums[i] >= nums[i+1]:
            i -= 1
        
        # After get this position 
        # find the first small numbers that is greater than nums[i]
        if i > 0:
            right = len(nums) - 1

            while nums[right]< nums[i]:
                right -= 1

            # Switch nums[i] and nums[right]
            nums[right], nums[i] = nums[i], nums[right]

        # Reorder the rest of the arrays from i+ 1 to the end
        new_left = i+ 1
        new_right = len(nums) -1
        while new_left < new_right:
            nums[new_left], nums[new_right] =  nums[new_right], nums[new_left]
            new_left += 1
            new_right -= 1
```
最初我认为这道题超简单，不就是从右到左遇见又大于左的话一对换就可以了，可是这种思想忽略了一种情况
比如 1 4 3 6 5 2， 如果简单的switch会变成 1 4 6 3 5 2
但实际答案应该是 1 4 5 2 3 6
具体分3步:
Step 1: 从右到左找出第一个降序的index，
Step 2: 把index 右侧的第一个大于index位置的数据和index调换
Step 3: 把index右侧重新排序
